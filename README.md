# Rouge MP3 Player

A hand-built portable MP3 player based on the Adafruit Feather ESP32 V2. Music is stored on a microSD card and streamed wirelessly to any Bluetooth A2DP speaker or headphones. Navigation is via a rotary encoder and four physical buttons, with a 240×240 TFT display and haptic feedback on every interaction.

---

## Features

- Bluetooth A2DP audio streaming — connects as a source to wireless speakers and headphones
- Artist → Album → Song library browser backed by a SQLite database on the SD card
- JPEG album art extracted from embedded ID3 tags, displayed in Now Playing
- Adjustable volume, screen brightness, and text size — all persisted across power cycles
- Haptic feedback (DRV2605L) with distinct effects for scroll, select, back, and error
- Battery monitoring with percentage and charging indicator in the status bar
- Flicker-free display via LovyanGFX off-screen sprite rendering and DMA transfer

See [Features.md](Features.md) for a complete feature list and the full roadmap.

## Quick Start

### Prerequisites

**Firmware:**
- [PlatformIO](https://platformio.org/) (CLI or VSCode extension)
- Git

**SD card indexer (desktop):**
- Python 3.8+
- `pip install mutagen`

### 1. Prepare the SD card

Your SD card must contain a `Music/` folder with MP3 files, and a `music.db` SQLite database generated by the indexer tool.

**Expected SD card layout:**
```
SD_CARD/
├── Music/
│   └── <Artist>/
│       └── <Album>/
│           └── *.mp3
└── music.db          ← generated by music_indexer.py
```

Run the indexer with the SD card mounted:

```bash
# macOS
python3 music_indexer.py /Volumes/SD_CARD/Music /Volumes/SD_CARD/music.db --verify

# Windows
python music_indexer.py D:\Music D:\music.db --verify

# Linux
python3 music_indexer.py /media/user/SD_CARD/Music /media/user/SD_CARD/music.db --verify
```

See [docs/INDEXER.md](docs/INDEXER.md) for full indexer documentation and troubleshooting.

### 2. Configure the Bluetooth target device

Edit `src/AudioManager.cpp` and update the device name to match your speaker or headphones:

```cpp
const char *headphoneName = "Your Device Name Here";
```

The name must match exactly what the device advertises over Bluetooth.

### 3. Build and flash

```bash
# Clone the repo
git clone <repo-url>
cd esp32-audio-player-test

# Build and upload (with board connected via USB)
pio run --target upload

# Monitor serial output
pio device monitor
```

### 4. First boot

1. Insert the prepared SD card
2. Power on — the loading spinner appears while the database loads into PSRAM
3. The main menu appears once loading is complete
4. Go to **Bluetooth** → **Reconnect** to connect to your speaker
5. Navigate to **Music** → **Artists** → select an artist → album → song → press Center to play

| Screen | Encoder action |
|--------|---------------|
| Any list (Artists, Albums, Songs, Menus) | Scrolls the list |
| Now Playing | Scroll 6+ ticks to enter **Volume** overlay; auto-exits after 2s idle |

## Settings

## Architecture Overview

Rouge uses a two-tier architecture:

**Desktop tier:** `music_indexer.py` scans the SD card's `Music/` folder, reads ID3 tags from every MP3, and writes a SQLite database (`music.db`) with normalized artist, album, and song records.

**Embedded tier:** On boot, the ESP32 loads `music.db` entirely into PSRAM and queries it for fast, zero-latency list browsing. Selected songs are decoded from the SD card using the Helix MP3 codec and streamed via Bluetooth A2DP to the connected speaker. All display rendering is done into a full-screen PSRAM sprite and flushed to the ST7789 in a single DMA burst, eliminating flicker.

### Module Map

| Module | File(s) | Responsibility |
|--------|---------|----------------|
| Display | `src/Display.cpp`, `include/Display.h` | Sprite rendering, all UI draw functions, layout constants |
| Navigation | `src/Navigation.cpp` | Button handlers, menu navigation logic, track skip |
| Audio | `src/AudioManager.cpp` | MP3 decode, Bluetooth A2DP source, volume control |
| Database | `src/Database.cpp`, `src/Indexer.cpp` | SQLite queries, artist/album/song list population |
| State | `src/state.cpp`, `include/State.h` | Global state, menu builders, navigation stack |
| Preferences | `src/Preferences.cpp` | NVS save/load for volume, brightness, text size |
| Battery | `src/Battery.cpp` | ADC voltage reading, LiPo discharge curve, charging detection |
| Haptics | `src/Haptics.cpp` | DRV2605L haptic effect playback |
| Album Art | `src/AlbumArt.cpp` | ID3v2 APIC frame parsing, JPEG decode into sprite |
| Encoder | `src/EncoderModule.cpp` | Quadrature decode, direction filtering, mode dispatch |
| Buttons | `src/Buttons.cpp` | Debounced button polling, ADC pin handling |

### Key Libraries

| Library | Purpose |
|---------|---------|
| LovyanGFX | ST7789 display driver with DMA and sprite support |
| arduino-audio-tools + arduino-libhelix | MP3 decoding and audio pipeline |
| ESP32-A2DP | Bluetooth A2DP source for wireless audio |
| SdFat | High-performance SD card file access |
| Sqlite3Esp32 | SQLite database in PSRAM |
| TJpg_Decoder | JPEG decoding for album art |
| Adafruit DRV2605 | Haptic motor driver |
| RotaryEncoder | Quadrature encoder input |
